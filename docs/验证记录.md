## 已验证项

- MySQL 8.4.10 上迁移版本/checksum、锁、重复 apply、checksum mismatch、失败停止、V003 回滚和信息架构字段注释。
- Catalog API 创建/发布/部署后重启读取；员工版本、Skill/Tool/Profile/ModelRoute 依赖固定；部署回滚和租户隔离。
- Session/Run 记录、上下文与版本快照、幂等提交、lease/fencing、TraceSpan/ToolInvocation/Usage/调整、故障注入事务回滚和 `UNKNOWN` 不重放。
- 消息正文和 Runtime 结果通过 LocalObjectStore 保存，MySQL 只保存对象引用/摘要/大小/保留/密钥版本；服务重启后授权读取。
- 上传 lease、SHA-256/大小校验、文件权限、fsync + 原子 rename、数据库故障恢复、过期/迟到上传、删除撤权、引用保护、GC 重试和对象重现重新入队。
- Fake identity seed 显式运行且幂等；MySQL app factory 使用连接池且关闭时释放；API startup 不创建用户/租户/平台。
- 未安装的 MinIO/S3/OSS/COS adapter 显式失败，不回落到 LocalObjectStore。
