# 目录与模块说明

## 后端目录

```text
backend/src/agent_platform/
├── api/              HTTP 路由、依赖注入和响应模型
├── application/      用例编排
├── domain/           领域对象和业务规则
├── ports/            可替换接口
├── adapters/         Fake、Runtime、模型和渠道适配器
├── infrastructure/  数据库、对象存储、队列和密钥
└── workers/          异步运行、投递和回收
```

## 前端目录

```text
frontend/src/
├── api/                          API Client 和响应类型
├── features/digital-employees/  数字员工功能域
├── test/                         测试环境初始化
├── App.tsx                       路由入口
├── main.tsx                      应用启动入口
└── styles.css                   项目基础样式
```

## 模块规则

| 模块 | 允许依赖 | 主要职责 |
|---|---|---|
| `api` | application、domain 类型 | HTTP 输入输出 |
| `application` | domain、ports | 业务流程编排 |
| `domain` | 标准库 | 业务规则和不可变对象 |
| `ports` | domain 类型 | 外部依赖接口 |
| `adapters` | ports、domain DTO | 外部系统实现 |
| `infrastructure` | ports | 技术设施实现 |
| `features` | api、UI 组件 | 前端业务页面 |

新增模块必须同步新增中文设计说明、流程图和测试入口。

后端控制面与 `harness-engine` 的依赖方向、Session 引用和 Run 流程见：[后端与 Harness 引擎关系](后端与Harness引擎关系.md)。
