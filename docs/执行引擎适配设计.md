## 适配边界

~~~mermaid
flowchart LR
  Control[ControlPlaneService] --> Port[RuntimeAdapter]
  Port --> Fake[FakeRuntimeAdapter]
  Port --> DeepSeek[DeepSeek Adapter]
  Port --> Codex[Codex Adapter]
  Port --> CLI[Generic CLI Adapter]
  Port --> Env[Workspace/Sandbox opaque refs]
~~~

RuntimeAdapter 只负责创建/恢复/执行/取消、能力声明、标准事件、Usage 和 opaque 引用。Runtime 内部 Agent Loop、上下文压缩、私有记忆、shell 和编辑器不由平台复制。

## Stdio Host 原型验证（2026-11-19）

Host 接收租户范围的 MCP Profile、租户上下文 SecretRef/工作目录解析器、可执行文件 allowlist 和工作目录根目录 allowlist。它以 command 与 args 数组启动子进程，不经 shell；Profile 必须是 ACTIVE。环境变量值在启动时短时解析，不进入 Host repr、Runtime 请求或持久化字段。工作目录解析后还会规范化路径并检查其位于 Worker 授权根目录中。

初始化后 Host 使用官方 MCP SDK 执行握手和 `tools/list`，只暴露 Profile 启用的工具；摘要按工具名称排序后覆盖名称和 input Schema。缺少启用工具、Schema 非法或摘要不匹配时拒绝运行并关闭进程。单次调用超时会关闭 Stdio 会话；Run 取消由创建会话的 owner task 处理。租约监控应通过取消该 Run owner task 触发清理，不能从另一个任务直接退出 SDK 的异步上下文。

Stdio proxy 子进程只接收 Profile 明确绑定的环境别名；SecretRef 值在 Worker 内短时解析，只通过临时进程环境传入，不写入 JSON/YAML patch。Harness SDK 每 Run 配置只有该 Profile 的命令、参数、cwd 和过滤目录；close 会终止 Runtime/MCP 子进程，lease 失效会关闭当前 Harness 并将 Session Home 隔离。StaffDeck Profile、只读 volume subpath/SecretRef 覆盖层、本机 Harness Run 和审批后 OFFLINE 创建均已验证；真实 DeepSeek provider 与生产密钥管理仍未验证。

数据输入沿用 V006 Profile：`command`、`args_json`、`working_directory_ref`、`environment_secret_refs_json`、`enabled_tool_names_json`、`tool_catalog_sha256`、`startup_timeout_ms`、`tool_timeout_ms` 和 `status`。运行时端口将 SecretRef 与工作目录解析显式绑定 `tenant_id`，Host 对解析路径执行 allowlist 检查；proxy 在 Harness MCP client 和上游 Stdio 服务之间再次限制 Run allowlist。

## 推荐的 EngineRequest 契约

EngineRequest 通过类型化字段接收 run_id、opaque SessionRef、opaque Session Home ref、prompt、EmployeeContext、Skill 指令/文件 manifest、有效 allowlist 对应的 EngineToolDefinition 和脱敏 metadata。MCP Profile launch 数据只存在于 RuntimeRequest/Worker factory，EngineRequest 不含 MCP SecretRef 映射或密钥明文。SecretRef 只由 Worker SecretResolver 在创建 Stdio proxy 时短时解析。

Agent 只能看到 READ/PREVIEW 工具。WRITE ToolVersion 由批准动作 Worker 执行。预览摘要、批准人、工具版本、参数摘要和一次性 challenge 都必须绑定同一 ApprovalRequest。

## 安全边界

Generic CLI 只接收参数数组、允许工作目录和超时；`shell=False`，拒绝空参数、宿主路径、特权、设备和长期凭据。Workspace/Sandbox Provider 先生成 opaque 引用，Runtime 只在授权环境内操作。

## 故障和恢复

- 启动失败：Run 标为 FAILED，保留能力和配置错误类别。
- Session 引用不匹配：返回 SessionMismatch，不替换历史引用。
- 取消未确认：保留 UNKNOWN，不伪造 CANCELLED。
- Runtime 只返回最终 Usage：记录 ESTIMATED/UNAVAILABLE，不猜测内部事件。
- 引擎切换：创建新 Runtime Session/Environment，旧引用保留在历史 Trace。
