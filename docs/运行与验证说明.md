# 运行与验证说明

## 启动后端

```bash
cd backend
.venv/bin/uvicorn agent_platform.main:app --host 127.0.0.1 --port 8000
```

## 启动前端

```bash
cd frontend
npm run dev -- --host 127.0.0.1
```

如果 `5173` 已被其他本地应用占用，Vite 会自动选择下一个端口。

当前 StaffDeck 占用 `5173` 时，本项目 Vite 前端会使用 `5174`。

## 验证命令

```bash
backend/.venv/bin/python -m pytest backend/tests -q
backend/.venv/bin/ruff check backend

cd frontend
npm test
npm run build
```

## API 冒烟

curl http://127.0.0.1:8000/api/health
