核心流程设计

所有流程都以租户授权和不可变快照为边界。

配置到 Session

管理员保存 Deployment 修订→解析用户/租户默认→创建 Session 固定来源→新 Run 使用固定快照

任务到答复

提交 Conversation turn→USER Message + QUEUED Run→Worker + Harness + MCP→Trace/Usage/ASSISTANT Message

写操作审批

PREVIEW 预览→提交者确认摘要→Approval Worker 一次执行→成功 / 失败 / UNKNOWN
UNKNOWN 不自动重试；Session Home 需要隔离并进行人工只读对账。内部 Trace 默认折叠，用户只看到可理解的阶段和最终结果。
