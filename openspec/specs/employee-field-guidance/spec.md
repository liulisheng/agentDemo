# employee-field-guidance Specification

## Purpose

帮助管理员理解员工资料、员工版本指令和 Skill 版本指令的用途与生效范围，从而把目录介绍、员工通用规则和可复用处理流程填写到正确字段。

## Requirements

### Requirement: 配置表单说明字段用途和生效范围

系统 SHALL 在员工资料、员工版本和 Skill 版本的相应表单字段附近展示简短用途说明，使管理员能够区分目录展示内容、每次运行的员工指令和绑定 Skill 后应用的可复用指令。

#### Scenario: 查看员工描述字段说明
- **WHEN** 管理员查看员工基本资料表单中的“员工描述”字段
- **THEN** 字段附近显示“用于员工目录和详情说明，不会作为模型运行指令。”

#### Scenario: 查看系统指令字段说明
- **WHEN** 管理员创建或编辑员工版本并查看“系统指令”字段
- **THEN** 字段附近显示“定义员工每次处理请求时都遵守的角色、规则和边界。”

#### Scenario: 查看 Skill 初始指令字段说明
- **WHEN** 管理员创建 Skill 版本并查看“初始指令”字段
- **THEN** 字段附近显示“描述可复用的处理步骤、触发条件和例外；只有绑定此 Skill 的员工版本会应用。”
